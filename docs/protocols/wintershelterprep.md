# Winter Shelter Preparation Protocol

**Version:** 1.0  
**System:** Paws & Peace Core

## Purpose

Ensure animals have safe, warm shelter during winter months.

## Roles Involved

- Builder
- Caretaker
- Safety

## Steps

### 1. Inspect Shelters

- Check for holes, drafts, or broken boards.
- Ensure roofs are intact.

### 2. Add Insulation

- Refill straw or bedding.
- Avoid blankets (they freeze when wet).

### 3. Improve Wind Protection

- Add windbreaks using plywood or tarps.
- Clear snow from entrances.

### 4. Water Access

- Prevent freezing by checking twice daily.
- Use insulated containers if available.
